# Data & AI Portfolio Roadmap

This repository is a hands-on learning journey covering enterprise data, analytics, Generative AI, Agentic AI and automation.

## Planned Case Studies

1. Enterprise Data Platform
2. GenAI Finance Assistant
3. Agentic AI for Data Investigation
4. Customer Analytics
5. Pharma Commercial Analytics
6. Financial Analytics
7. Procurement Analytics

## Learning Approach

Each case study will include:

- Business problem
- Data and architecture
- Technical approach
- Implementation
- Governance and security considerations
- Results and insights
- Lessons learned

## Guiding Principle

Build practical, enterprise-oriented solutions using synthetic or anonymized data while demonstrating sound architecture, engineering, analytics and AI practices.
